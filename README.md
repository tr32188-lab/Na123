
# 🌐 MY PORTFOLIO

เว็บไซต์ E-Portfolio (แฟ้มสะสมผลงานออนไลน์)  
จัดทำขึ้นเพื่อแนะนำประวัติส่วนตัว ประวัติการศึกษา ทักษะ ความสามารถ และผลงานของผู้จัดทำ

## 👨‍🎓 ข้อมูลผู้จัดทำ

- **ชื่อ:** นายณภัทร์ กระสินพันธุ์
- **ระดับชั้น:** มัธยมศึกษาปีที่ 6/13
- **เลขที่:** 14
- **ความสนใจ:** วิศวกรรมเครื่องกล รถยนต์ และงานช่าง
- **เป้าหมาย:** ศึกษาต่อคณะครุศาสตร์อุตสาหกรรม สาขาวิศวกรรมเครื่องกล

## 📌 จุดประสงค์ของเว็บไซต์

1. เพื่อแนะนำประวัติส่วนตัว
2. เพื่อนำเสนอประวัติการศึกษา
3. เพื่อรวบรวมทักษะและความสามารถ
4. เพื่อแสดงผลงานและกิจกรรมต่าง ๆ
5. เพื่อใช้เป็นแฟ้มสะสมผลงานออนไลน์ในการศึกษาต่อ

## 🛠️ เทคโนโลยีที่ใช้

- HTML5 ใช้สร้างโครงสร้างเว็บไซต์
- CSS3 ใช้ตกแต่งเว็บไซต์
- Google Fonts ใช้สำหรับรูปแบบตัวอักษร
- GitHub Pages ใช้เผยแพร่เว็บไซต์

## 📂 โครงสร้างไฟล์

```text
my-portfolio/
│
├── index.html
├── profile.jpg
└── README.md
```

## 📖 ส่วนประกอบของเว็บไซต์

- Home : หน้าแรก
- About Me : ประวัติส่วนตัว
- Education : ประวัติการศึกษา
- Skills : ทักษะและความสามารถ
- Portfolio : ผลงานและกิจกรรม
- Contact : ช่องทางการติดต่อ

## 🚀 การเผยแพร่เว็บไซต์

เว็บไซต์นี้เผยแพร่ผ่าน GitHub Pages

วิธีเปิดใช้งาน:
1. สร้าง Repository บน GitHub
2. อัปโหลดไฟล์เว็บไซต์
3. เข้า Settings
4. เลือก Pages
5. เลือก Branch เป็น main
6. กด Save

## 🎯 สรุป

เว็บไซต์ E-Portfolio นี้เป็นผลงานที่จัดทำขึ้นเพื่อฝึกทักษะการสร้างเว็บไซต์ด้วย HTML และ CSS รวมถึงการใช้งาน GitHub Pages สำหรับเผยแพร่ผลงานบนอินเทอร์เน็ต และเป็นการรวบรวมข้อมูลเพื่อแสดงตัวตน ความสามารถ และเป้าหมายทางการศึกษาของผู้จัดทำ
